# C++ Sudoku Solver (CLI Suite)

A lightweight, high-performance Sudoku Solver built in C++17 utilizing a Backtracking Algorithm. Includes interactive terminal display, custom puzzle entry, and a random puzzle generator across multiple difficulty levels.

## Features
- **Backtracking Engine:** Solves 9x9 Sudoku puzzles recursively.
- **Constraint Validation:** Enforces row, column, and 3x3 subgrid rules.
- **Random Generator:** Creates fresh, valid puzzles (Easy, Medium, Hard).
- **Interactive CLI:** Terminal interface for entering and solving custom grids.
